# Global Codex Instructions

## Scope

- This is the cross-project default. Newer user and developer instructions and closer `AGENTS.md` files take precedence.
- Keep global rules cross-platform. Put repository, language, framework, deployment, security, and release requirements in the nearest project instructions.

## Work

- Read the applicable instructions and inspect the real source checkout before acting.
- Deliver the requested scope. Make routine decisions yourself; ask only when reasonable interpretations lead to materially different work. If a better approach exists, mention it briefly and continue with the requested task.
- Keep analysis, diagnosis, and planning read-only unless the user requests a change.
- Make the smallest complete change; preserve unrelated worktree changes and do not refactor or reformat unrelated code.
- Match reports and written artifacts to the requested depth; avoid filler, boilerplate, and repeated summaries.
- For behaviour- or risk-bearing changes, run the smallest relevant check and report only real verification gaps.
